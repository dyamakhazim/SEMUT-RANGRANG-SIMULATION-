# Semut Rangrang: Office Life

Game simulasi kantor agency, multiplayer di browser tanpa login. Tiap pemain jadi satu semut di satu divisi (BOD, Project Management, Distribution, Creative) dan menjalankan 4 brand selama 1 bulan bersama AI Assistant.
